# 本栖湖 · 浩庵露营场 (Motosuko Solo Camp)

基于 **Blender 5.3 (bpy)** 建模管线与 **Three.js** 实时渲染引擎打造的日本实景仿真单人露营互动游戏，原型取景自日本山梨县富士五湖·本栖湖（浩庵露营场）。

## 核心特性
- **Blender 5.3 实景 PBR 资产管线**：通过 `blender/build_all_assets.py` 自动生成并导出 33 个高精度 `.glb` 模型（2048×2048 富士山与放射状雪沟、60 边棉布钟形帐篷、蛋卷桌、克米特椅与羊毛毯、双煤油风灯、Snow Peak 焚火台、橡木劈柴墩与手斧、铸铁锅、A5 和牛、珐琅露营锅、手冲细嘴壶与 Hario V60 滤杯、Snow Peak 钛杯、日本红枫/杉木/秋叶灌木与芒草）。
- **实景自然地貌与 24h 天象**：
  - 真实摄影级林地地表纹理 + 四重生态混合地形（湿润水岸、金暖砂砾滩、苔藓松针落叶营地、红橙金绿日本秋叶后山）
  - 实时平面镜面反射「逆さ富士」本栖湖水面
  - 支持一键切换 **秋日暖阳 (15:24) / 粉金晚霞 (17:44) / 银河星夜 (21:30) / 清晨朝烧 (06:22)**
- **拟真露营生火与野炊玩法**：
  - 橡木树墩挥斧劈柴（原木 → 劈柴 → 引火细柴）
  - 热力学仿真篝火（打火石火星引燃 → 冒烟起火 → 火吹棒吹气助燃提温至 700°C+）
  - 铸铁平底锅双面煎制 A5 和牛（实时美拉德色泽变化、滋啦声与抛翻动画）
  - 珐琅露营锅煮沸热咖喱汤 & Hario V60 长按注水手冲咖啡
  - 坐上克米特椅面朝富士山与篝火品茗
- **100% 程序化 Web Audio 空间声场**：实时合成湖浪、山风、篝火噼啪、烤肉滋啦、水沸、劈柴、碎石脚步声、秋虫与晨鸟。

## 快速运行
```bash
npm install
npm run dev
```
浏览器打开 `http://127.0.0.1:5173/` 即可游玩。

### 重新通过 Blender 生成 3D 资产（可选）
项目已自带导出好的 `public/models/*.glb`。如需修改并重新导出模型，请安装 Blender 并运行：
```bash
blender --background --python blender/build_all_assets.py
```

## 操作说明
| 按键 | 功能 |
| --- | --- |
| `WASD` / `Shift` / `C` | 移动 / 轻跑 / 蹲下照看篝火 |
| `E` 或 `鼠标左键` | 交互、劈柴、打火引燃、翻面烤肉、长按手冲注水、坐克米特椅 |
| `F` | 对焚火台吹气助燃 / 放回手持装备 |
| `G` | 切换天象时刻（秋日暖阳 / 粉金晚霞 / 银河星夜 / 清晨朝烧） |
| `T` | 切换时间流速（×1 / ×12 / ×60） |
| `Q` | 切换 流畅实景 / 电影光晕 (HDR Bloom) 画质 |
| `P` | 胶片相机拍照并保存 PNG 明信片 |
| `H` | 收起 / 展开露营手账 |
